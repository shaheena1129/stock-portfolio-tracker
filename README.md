# 📈 Stock Portfolio Tracker

A simple and beginner-friendly Python project that helps users track their stock investments. The program allows users to enter stock names and quantities, calculates the total investment value using predefined stock prices, and saves the portfolio details to a text file.

---

## 🚀 Features

- 📌 Accepts stock name and quantity from the user
- 📊 Uses a dictionary to store stock prices
- 🧮 Calculates total investment value
- 📝 Displays portfolio summary
- 💾 Saves portfolio details into a text file
- ✅ Easy to understand and beginner-friendly

---

## 🛠️ Technologies Used

## 📋 How It Works

1. Enter the stock name.
2. Enter the quantity of shares.
3. The program checks whether the stock exists.
4. It calculates the total investment value.
5. The portfolio summary is displayed.
6. The details are saved in a text file named `portfolio.txt`.
